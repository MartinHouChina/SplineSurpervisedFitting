# 2026-09-23：Stable K32 短程消融结果

本轮没有修改原 V16 架构或原训练入口，也没有替换已有正式模型。新增独立实验入口，复用 `overnight_stable_k32_3090_r1.pt`，Proposal 训练0轮。

## 设置与边界

- 本机 CUDA / GTX 1070，三组各4轮，batch16，合成训练64条。
- 验证29条、测试29条：各包含合成源K4..24逐K一条，UJI、NaturalEarth、USGS、程序生成工业等距线各2条。外部数据不用于训练；工业等距线不是实测工业曲线。
- MSE≤5e-5，最大采样点平方误差≤5e-4，候选内部节点最多32。没有公共插入修复、测试时贪心搜索或阈值放宽。
- 教师固定初始化 Proposal 的 t/U；只从可行集合中删节点，缓存一次后三组共享。失败教师不参与优化，但全部验证/测试案例保留在分母。
- A/B/C 相同初始权重、数据顺序与筛选目标。A/B末轮筛选权重逐位一致检查通过。

以下是末轮结果，不是选择最优轮次后的结果：

| 输出 | 测试双阈值通过率 | 平均内部节点 | 平均MSE |
|---|---:|---:|---:|
| 原始初始化模型 | 75.9%（22/29） | 15.28 | 3.719e-5 |
| A：固定几何，筛选训练4轮 | 34.5%（10/29） | 13.66 | 1.197e-4 |
| B：原解码器冻结，筛选训练4轮 | 58.6%（17/29） | 13.66 | 6.037e-5 |
| C：筛选＋教师几何监督训练4轮 | 34.5%（10/29） | 12.93 | 8.835e-5 |

验证选出的最佳轮次：A第2轮，B/C均第0轮。因此 B/C 的 best 测试结果与原始模型相同，并不是训练改善。完整结果同时保留 best 和 last，失败误差未被删除。

## 可以得出什么

1. **不能直接去掉几何更新。** A/B 使用相同末轮筛选权重、相同数量，B明显更好。这至少说明在该模型与该样本组上，原解码器对当前预测集合有用。
2. **教师解复现问题仍存在。** 验证集固定 Proposal 教师有27/29条达到双阈值；这些可行教师掩码重新走原解码器后，13/27条仍通过（48.1%）。不同掩码下的几何更新并没有一致保持教师可行性。
3. **短程拟合标签不等于获得稳健精简能力。** 三组节点数都减少，但末轮通过率下降；C加入完整几何监督仍未在4轮内解决这一问题。这不支持“单纯加大训练轮数必然改善”，也不能证明所有几何监督无效。
4. 新试验并不排除其他学习率、教师或训练规模能改善，只是在当前有限时间下，没有证据支持立即投入通宵重训或替换正式模型。

这是单种子、小样本诊断，不是统计显著性结论。不能将本轮75.9%与此前不同61条样本的59.0%直接比较，也不能据此选超参数后继续把本轮测试集作为最终论文测试。

## 产物

目录：`outputs/ablations/short_ablation_k32_pilot_20260923_r1/`。

- `summary.csv` / `results.json`：包括全部来源、最优和末轮、MSE、最大平方误差、节点数、计时。
- `ablation_last_comparison.png`：同末轮对照；`ablation_comparison.png`：验证最优对照，显示对应epoch。
- `teacher_replay_before.json`：同教师掩码前后的几何可行性。
- 各组 `test_best.json` / `test_last.json`：实际参数、内部/完整节点向量、控制顶点、稠密曲线和逐点残差。

时间是本机单次探索性计时，包含网络与一次标准 B 样条重拟合，不含离线教师。A仍经过现有解码计算，只将几何残差设为零；本轮未做算子裁剪，不应据此推断固定几何部署的极限速度。

新增及关联回归共115项通过，包含真实微型三组训练、恢复、冻结参数、教师双约束及Linux启动器。图表在保存的原始统计上补充了末轮版本，没有重新计算或修改实验误差；数值试验执行时的源码指纹保存在 `protocol.json`。
