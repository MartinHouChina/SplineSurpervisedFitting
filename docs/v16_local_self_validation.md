# v16 Keep 状态恢复档：本地实训与组件验证

结论：本次小规模验证未通过，不建议按当前恢复档直接进行服务器长训。代码中的交互与梯度机制正常，但尚未证实“维持拟合阈值的同时减少节点”。最佳检查点主要靠近乎全留维持拟合，末轮减少节点后发生明显退化。

## 验证协议

本次检查不是单元测试代替精度评估，而是在 GTX 1070 8 GB 上运行真实训练及标准 B 样条部署。被测代码对应 `2ac4b84`；本次仅新增诊断脚本、产物与报告，没有在测试中修改网络或修复预测结果。

- 初始化：旧 r2 `candidate_selection_v16_mse1e-4_k56_ordered_highk_softcost_linux_r2_joint_fast.pt`，完整继承权重。
- 架构：Keep 状态交互、全局候选间隔调整、Count–Keep 耦合和筛选边界损失全部开启。
- 容量与阈值：56 个内部候选，source K=4..56，标准平均平方欧氏距离 MSE≤1e-4；不开方，不除坐标维数。
- 训练：每阶段 192 条固定认证合成样本（两个阶段的高 K 采样比例不同，阶段内不逐轮重采样），192 个采样点，Batch=16，Proposal 4 + Joint 24 代，即 48 + 288 次更新。训练 seed=20260917。
- 验证：64 条独立合成曲线，seed=30260917；包含 8 个指定 K=56 样本、8 个指定高 K 样本，加随机抽到的高 K 曲线。
- 学习率：Proposal/Selector 5e-5、decoder 1e-5；Joint 固定 Proposal。Teacher 策略为 `synthetic_anchor_counterfactual`，最多 8 次局部交换探测。
- 独立配对测试：K=4..56 每 K 一条，共 53 条合成曲线；UJI、Natural Earth、USGS 的 test split 各 3 条。测试种子 9100000000，各检查点使用同一批曲线。
- 组件诊断：K={4,8,16,24,32,40,48,56} 各 2 条，共 16 条独立曲线。另在这些曲线上生成贪心固定 Proposal 子集，明确与训练的 anchor/counterfactual Teacher 区分。
- 部署统一使用 CPU float64 标准 refit，零 ridge、零平滑正则、端点插值。所有原生 Ours 数据都没有加回、数值重定位或失败回退。

本次是缩小规模的可行性检查，不是完整推荐档（600 样本、8+24 代）的最终性能估计。数据量、Proposal 代数与 Batch 均有缩减，不能由此证明所有更大规模训练都会失败；也不能因短训指标好转而宣称整体方法达标。旧 r2 曾使用真实数据预训练，外部 test split 检查不代表纯合成到真实域的零样本泛化。

## 组件诊断口径

对同一模型、同一曲线、同一掩码分别求解：

| 分支 | 参数 t | 节点 U |
|---|---|---|
| 原几何 | Proposal | Proposal 中被选中的节点 |
| 仅参数更新 | Decoder | 将原节点映射到 Decoder 参数域 |
| 仅节点更新 | Proposal | 将 Decoder 节点映射回 Proposal 参数域 |
| 完整更新 | Decoder | Decoder 的选中节点 |

节点位移在统一的归一化采样序号域比较，避免把参数化变化误当成节点移动。跨域映射使用单调分段线性插值，因此这些是操作性消融，不是对曲线几何贡献的精确可加分解。

另外比较自由掩码、贪心 Teacher 掩码、强制采用 Teacher 数量的网络 Top-K 掩码。独立曲线不会套用训练缓存的行索引。原始数值 Teacher 的通过率与其通过 Decoder 后的通过率分开列出。

## 初始模型核验

完整迁移后的 `.initial.pt` 与旧 r2，在 53 条合成、9 条真实测试曲线上的 MSE 和节点数逐项一致。新增零初始化分支没有破坏初始部署；初始合成通过率为 45/53=84.9%，平均 MSE=8.404e-5，平均 K=43.00。K≥45 的 12 条仅 4 条通过，K=56 的 1 条失败，不能把整体通过率当成高 K 已解决。

在组件诊断的 16 条独立曲线上，旧 r2 的结果为：

| 分支 | 通过数 | 平均 K | 平均 MSE |
|---|---:|---:|---:|
| 全候选 Proposal | 12/16 | 56.00 | 1.675e-4 |
| 自由掩码，仅删除不微调 | 3/16 | 39.50 | 8.331e-4 |
| 自由掩码，仅参数更新 | 3/16 | 39.50 | 8.074e-4 |
| 自由掩码，仅节点更新 | 12/16 | 39.50 | 1.744e-4 |
| 自由掩码，完整 Decoder | 14/16 | 39.50 | 1.550e-4 |
| 贪心 Teacher 掩码，原几何 | 12/16 | 31.56 | 2.116e-4 |
| 同一贪心掩码，完整 Decoder | 3/16 | 31.56 | 8.670e-4 |
| Teacher 数量 + 网络 Top-K + Decoder | 2/16 | 31.56 | 8.982e-4 |

这个结果表明：旧 r2 的自由筛选与重定位已经相互适配，重定位救回 11 条曲线；单看筛选后原位置误差会低估这个组合。反过来，Proposal 域数值上可行的另一个掩码，交给该 Decoder 后不一定可行。修正参数域位置损失并不自动解决这种组合与几何的兼容问题。

## 缓存、筛选与微调的定位

完整 192 条训练 Teacher 数据与冻结 Proposal 的指纹匹配。固定抽查索引 0..15 的数值结果：缓存与 CPU 部署 refit 均通过 12/16，没有判定翻转；MSE 最大绝对差 1.866e-8，平均绝对差 3.795e-9。当前证据不支持“标签串行错位”或 GPU/CPU 求解器差异是主要原因。

末轮模型在这 16 条训练样本上的同口径 CPU 检查：

| 掩码 | 原 Proposal 几何通过数 | Decoder 后通过数 | 平均 K |
|---|---:|---:|---:|
| 缓存 Teacher 掩码 | 12/16 | 10/16 | 38.13 |
| Teacher 数量 + 网络 Top-K | 1/16 | 2/16 | 38.13 |
| 自由预测 | 0/16 | 0/16 | 36.25 |

只看 Teacher 原本可行的 12 条，强制正确数量的 Top-K 节点召回率为 0.581，掩码完全相同的比例为 1/12，其 Decoder 后也仅 1/12 通过。不可行 Teacher 经常全保留，不能把这类容易匹配的掩码混入分母后误称排序良好。掩码不完全相同本身不证明不可行；此处同时用实际 refit 证实了组合选择的不足。

训练末轮日志也显示相同方向：数值 Teacher 通过率 67.7%，Teacher 掩码经过学生后 62.5%，自由部署 0%；可行 Teacher 条件下，给定正确数量的 Top-K 召回仍约 0.672、完全匹配率约 0.7%。这些是批次加权的训练指标，不冒充独立测试集结果。

参数变化核验确认新增模块确实参与了学习：Keep 状态嵌入相对初始化的权重变化范数约 0.0475，全局间隔头约 0.0022，KeepHead、节点重定位与参数更新权重也都发生变化。不能用“开关未开启”解释此次失败。

独立 16 条组件诊断进一步区分了排序与微调：

| 同一批曲线上的分支 | 旧 r2：通过 / K | 最佳 epoch 14：通过 / K | 末轮 epoch 28：通过 / K |
|---|---|---|---|
| 自由掩码，原几何 | 3/16 / 39.50 | 12/16 / 54.88 | 0/16 / 30.81 |
| 自由掩码，完整 Decoder | 14/16 / 39.50 | 13/16 / 54.88 | 0/16 / 30.81 |
| 各自 Proposal 的贪心掩码，完整 Decoder | 3/16 / 31.56 | 13/16 / 31.50 | 13/16 / 31.50 |
| 贪心数量 + 网络 Top-K，完整 Decoder | 2/16 / 31.56 | 1/16 / 31.50 | 1/16 / 31.50 |

因此，新模型在给定合适掩码时有能力以较少节点拟合；其微调对数值 Teacher 的适配确有改善，但自由选择能力没有跟上。末轮同为 6 个节点的首条 K=4 案例，贪心掩码+Decoder MSE=5.167e-5，网络排序 Top-K+Decoder MSE=1.874e-3，不能用“节点数量不够”解释这个差距。

同一 16 条曲线的曲线内 Keep 概率标准差均值，由旧 r2 的 0.2305 降至最佳模型 0.00259、末轮 0.00253。末轮并非全部概率饱和到 1，仍出现近乎同分，表明候选区分度退化。统一域节点位移均值也由旧模型 0.0464，变为最佳模型 0.000402、末轮 0.00392。旧的“自由选集+较大重定位”协同被改变，而新的排序未能支撑简化。所有这些诊断分支的参数及内部节点均有限、有序、位于合法参数域，未发现输出乱序或 NaN。

## 结论与下一步顺序

1. 完整热启动正确，显式 Keep 状态交互可工作，节点确实会移动；这些机制不等于已经学到有效简化。
2. 不能再把主要问题笼统归为节点数量。前期几乎全留掩盖了排序问题，后期 Count 把数量压下来后，错误组合导致拟合崩溃。单纯调 beta/阈值不能补回错选的节点。
3. 固定 Proposal 上的可行 Teacher 掩码，和旧 Decoder 的非平凡重定位不天然兼容。本轮 Teacher 掩码的几何适配有所改善，但原自由部署能力退化。下一步应以最终部署几何上的结果校准 Teacher，并在固定数量下先验证组合排序；不能只让数量逼近 Teacher 而不检查删的是哪些节点。
4. Keep 边界损失下降没有带来正确数量下的排序提升，节点间概率反而趋同。应做受控消融、保留旧部署能力的约束和可替代节点组合监督，不能继续仅凭 BCE/F1 或数量 MAE 判断筛选是否成功。本轮没有单独消融每个新损失，不能断言其中某一项单独导致全部退化。
5. 高 K 的全候选拟合失败是独立上游问题；在保持 Kc=56 的要求下，应先验证候选位置/参数预测的可行性，再讨论削减数量。增加训练代数或换更快显卡本身并不能证明这个问题已解决。

因此先保留旧 r2 作为实测参照，不把此次新 checkpoint 作为改良成功的模型。下一轮修正应先通过本地相同的筛选/微调/原生部署测试，再启动大规模训练。
